🔒

Your secrets stay local秘密留在本地

Credentials remain in your OS keychain. Agents receive connection context and file references, never raw secrets. 凭据保留在操作系统钥匙串中。Agent 拿到的是连接上下文和文件引用，而不是原始秘密。

⚡

Same workspace, two roles一个工作区，两种角色

You control scope and approval. Your Agent finds files, runs checks, and returns evidence—all in the same local workspace. 范围与授权由你决定；Agent 查找文件、执行检查、返回证据，全都在同一个本地工作区里完成。

🎯

Tag-based scope control用标签圈定范围

Organize hosts with tags. Keep production separate from staging. One command bounds the entire task to the right hosts. 用标签组织主机，把生产和预发布分开。一条命令就能把整个任务限定在正确的主机上。
